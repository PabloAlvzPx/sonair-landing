# SONAIR ONE — Landing page generada por IA

Landing page de un producto ficticio (auriculares over-ear SONAIR ONE), generada por un modelo de IA como parte de mi video comparativo de modelos **IA al minuto**.

🔗 **Demo:** https://pabloalvzpx.github.io/sonair-landing/

## Qué hice yo

- Diseñé el prompt y las especificaciones del producto (características, precio, tono de marca y secciones).
- Evalué el resultado generado por Claude Opus 5.5: estructura HTML, accesibilidad, diseño responsive, interactividad y calidad del código.
- Revisé y publiqué el proyecto.

## Qué incluye la página

- Diseño responsive para escritorio y móvil.
- Simulador interactivo de cancelación de ruido según modo y entorno.
- Calculadora de batería según horas de uso.
- Ficha técnica, preguntas frecuentes y resumen de compra simulado.
- Buenas prácticas de accesibilidad: etiquetas ARIA, enlace para saltar al contenido y textos alternativos en imágenes.

## Tecnologías

HTML · CSS · JavaScript (sin frameworks)

## Nota

SONAIR es una marca ficticia creada para esta prueba. El código fue generado por IA; mi trabajo fue el diseño del prompt, la evaluación y la publicación.
